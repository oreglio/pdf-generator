# Icône Folio

`folio.png` est l’icône source, avec transparence, utilisée par la fenêtre macOS.
`build_macos_app.py` produit les résolutions macOS avec `sips`, puis le fichier
`.icns` avec `iconutil`. La conversion conserve le dessin original.

Création via l’outil intégré `image_gen`, le 16 septembre 2026. Prompt final :

> Create a beautiful polished macOS application icon for a personal notebook and PDF planner app named Meetings & actions. Single icon, square 1024x1024 canvas. Deep forest green rounded squircle tile, ivory closed paper notebook slightly turned in perspective, subtle embossed checklist of three lines on the cover, small sage ribbon bookmark, refined tactile paper and satin materials, gentle restrained dimensional lighting. Premium minimal productivity app aesthetic, exceptionally legible silhouette at 32 pixels, generous clean margins outside the rounded tile. Truly transparent outside the tile. No text, no letters, no watermark, no mockup screen, no additional icons. The app's existing brand color is #235c4f and warm ivory. Save the finished icon as a usable image file.

Le nom **Folio** a été retenu après génération ; l’icône ne contient aucun texte.
